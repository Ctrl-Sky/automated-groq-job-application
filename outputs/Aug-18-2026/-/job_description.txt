Summary
As an experienced .NET Software Engineer, you will play a key role in driving the success of our Supply Chain Management (SCM) applications and the technical development and scaling of our core enterprise systems. Operating within a modern .NET ecosystem, you will actively contribute to the end-to-end software development lifecycle (SDLC), driving the design, enablement and implementation of high-performance product features. In this role, you will combine strong hands-on technical execution with team collaboration, helping to establish engineering best practices, designing robust APIs and ensuring overall software excellence.

Detailed Description
Full professional level; applies software engineering expertise in a specific area of specialization. Work is performed within established professional standards, technical guidelines and project objectives. Works on problems of moderate to diverse scope where analysis of technical requirements, system architectures and data schemas requires evaluation of identifiable factors. Exercises technical judgment within defined procedures and software development practices to determine appropriate action. Receives general instructions on routine development tasks and detailed instructions on new projects or complex system assignments. Builds productive collaborative relationships across development, QA and business analyst teams.

Performs tasks such as, but not limited to, the following:

Contribute significantly to the architecture, design and end-to-end delivery of scalable enterprise web applications using ASP.NET Core MVC and .NET 10.
Play a key role in the new features enablement process, designing and building brand-new product capabilities from scratch to deliver strategic business value.
Establish robust architectural foundations, design RESTful APIs and optimize data flows integrated with Oracle DB.
Deliver clean, maintainable and scalable code by strictly adhering to SOLID principles and Clean Code practices.
Actively participate in Agile/Scrum ceremonies including daily stand-ups, sprint planning, backlog refinement and retrospectives to ensure consistent sprint delivery and alignment.
Manage modern development workflows in GitLab, utilizing standardized branching strategies, merge request processes and CI/CD practices.
Collaborate closely with team members, sharing technical knowledge on modern .NET design patterns, coding standards and development best practices.
Ensure application reliability and stability by defining and implementing code testing standards, structured debugging and proactive performance optimization.
Proactively identify and resolve technical debt, modernize user interfaces and enhance application stability, security and performance.
Collaborate with IT/Business partners, cross-functional teams and stakeholders to translate business requirements into clear technical specifications.
Maintain comprehensive technical documentation for architectural designs, system configurations and database schemas to ensure long-term maintainability.
Knowledge/Skills/Competencies
Minimum of 5 years of professional experience in the .NET ecosystem, with a strong passion for modern C# features and ASP.NET Core.
Solid expertise in software design and architecture (Dependency Injection, Repository Pattern, Clean Architecture and Modular Design).
Advanced proficiency in Database Architecture and SQL, with experience optimizing Entity Framework Core integrated with Oracle DB (experience with other relational databases such as PostgreSQL or SQL Server is highly acceptable).
Competency in web development and frontend integration, combining ASP.NET Core MVC with JavaScript to build highly interactive, responsive and performant user interfaces using UI components (such as Telerik UI), along with basic HTML and CSS skills.
Hands-on experience with version control and modern Git workflows (GitLab, branch protection, Merge Requests) along with exposure to CI/CD automation pipelines.
Proven ability to work independently, take technical ownership of features, manage priorities and drive high quality standards through constructive code reviews.
Actively participate in technical discussions, business requirements alignment and specifications review with managers, architects and stakeholders within the local Canada timezone (EST).
Demonstrate flexibility to collaborate across global timezones, ensuring daily alignment with the manager in Romania and cross-functional development teams in Europe and Asia.
Exceptional verbal and written English skills for cross-cultural collaboration, negotiating technical requirements and explaining complex .NET concepts to both technical and non-technical stakeholders.
Self-driven, proactive mindset with a focus on writing highly scalable, long-term maintainable code and a desire to contribute to architectural discussions.
Experience working in an Agile/Scrum environment with a solid understanding of sprint cycles, collaborative delivery and continuous improvement is preferred.
Understanding of Supply Chain Management (SCM) processes or ERP workflows is considered a strong asset (openness and willingness to learn these business processes is highly valued).
Knowledge or experience with UI frameworks (e.g., Telerik UI for ASP.NET Core with Ajax Binding, Tag Helpers) is a strong asset.
Prior knowledge of Java or Java ADF is not required, though any basic familiarity with these technologies is a welcome asset.
Openness to utilizing modern development tools and AI-assisted engineering practices is preferred.
